# CC-036 — Task completion attestations (EAS)

Listed as unchecked in the README project status, marked "roadmap, post-monetisation".
On-chain attestation per completed task, surfaced on the worker's reputation.

Currently reputation is computed from escrow event logs plus a DB fallback
(`src/lib/reputation/index.ts`), which works but is not independently verifiable by a third
party. Attestations are what make the reputation claim in the README actually true.
