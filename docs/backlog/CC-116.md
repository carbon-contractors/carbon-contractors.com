# CC-116 — Reputation score renders with no explanation of what it means

## Problem

NOR-349 ("Reputation?"): the dashboard's reputation card shows a number
and a four-cell breakdown grid (Completion / Volume / Recency / Stake)
with no prose anywhere saying what any of it is, how it's computed, or
why a worker should care. The PO's walkthrough reaction was a question
mark — which is the correct reaction to an unexplained number.

## Fix

One plain-language explainer line under the stats row, stating the
actual arithmetic from `src/lib/reputation/compute.ts`:

> Score is 0–100 from four parts: completed ÷ total tasks (max 40),
> task volume (max 20), recent activity (max 20), and your stake
> (max 20). Disputes reduce it. See Learn for how offers reach you.

with a link to the Learn hub. The "New — no history yet" state
(CC-010) is untouched.

## Acceptance

- [x] A signed-in worker with any history sees one sentence explaining the
  score, accurate to the implementation, linking to Learn.
- [x] The new-worker state is unchanged.
