Confirm 16.2.6 is at or above the patched version for the advisory, close this if so, and

## Answered 2026-07-30 — **no, it is not closed.** Stays open pending the bump.

`npm audit` after a clean `npm ci` shows `next` 16.2.6 carrying **nine** advisories, including
**GHSA-q8wf-6r8g-63ch — denial of service in the Image Optimization API via SVG.** So the guess in
this issue ("likely already fixed") was wrong: 16.2.6 is *not* at or above the patched version.

The fix is `next@16.2.12`, a **non-major** bump, which also clears the `postcss` and `sharp`
advisories that resolve through Next.

Two of the other eight matter more than the DoS one:

- **GHSA-6gpp-xcg3-4w24** — middleware/proxy bypass in App Router. `middleware.ts` *is* the
  coming-soon gate, so read this one first and check whether the Turbopack + single-locale
  precondition applies here.
- **GHSA-955p-x3mx-jcvp** — unauthenticated disclosure of internal Server Function endpoints.

On the CI question in "Do": CI has **not** been failing silently. It has not been *running*. The last
run on `master` was 2026-05-09 and it succeeded; nothing has pushed to `master` since. The audit gate
will fail on the next push — `npm audit --audit-level=high` currently exits 1.

Full advisory breakdown and the sequencing (including why the `wagmi`/`ws` chain should be done as
part of `CC-043` rather than separately) is in **`CC-061`**. Close this once the Next bump lands and
`npm audit` confirms GHSA-q8wf-6r8g-63ch is gone.
