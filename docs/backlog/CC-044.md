# CC-044 — Build the standalone basedhuman-mcp server package

Migrated from NOR-300. A distributable MCP server, separate from the Next.js route that
serves `/api/basedhuman.mcp` today.

## Tools
`listTasks`, `getTask`, `submitBid`, `completeTask`, `getAgentStatus`.
`completeTask` **must** read the contractor wallet from on-chain escrow state, never from
Supabase — see CC-037.

## Decisions still open
STDIO vs HTTP/SSE transport; challenge-response auth reusing the NOR-178 pattern already in
`src/app/api/basedhuman.mcp/route.ts`; Zod validation on every input; x402 integration.

Blocked by CC-045 — do not publish to npm beyond a name reservation until the supply-chain
hardening is done.

Related: CC-045, CC-046.
