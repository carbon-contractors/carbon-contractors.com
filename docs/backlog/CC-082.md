# CC-082 — CarbonEscrow v2 and Sepolia redeploy

Specified by `ADR-0001` (D1, D2, D4, Amendment 1). This is step 1 of that ADR's handover and
**everything else in the money path sequences behind it.**

## Why this exists

`CarbonEscrow` has exactly one clock: deadline → `expireTask` → refund agent. Silence therefore
always resolves in the agent's favour, which produces the loss case neither `CC-081` nor `CC-075`
named: **the worker delivers, the agent never calls `completeTask`, the deadline passes, and the
agent is refunded automatically.** No bad actor required. The worker has no path to payment that
does not depend on the agent's continued goodwill.

## Scope

**Contract additions**

- `submitWork(taskId, evidenceHash, specVersionAck)` — `task.worker` only, state `Funded` →
  `Delivered`, records `submittedAt`, opens the review window.
- `releaseAfterReview(taskId)` — **pull-payment, claimed by the worker** (Amendment 1 A1.2). Pays
  the worker when the review window closes with no valid failing verdict presented.
- **EIP-712 signed verdicts, not a `postVerdict` transaction** (Amendment 1 A1.1). The verdict is
  signed off-chain; whoever claims presents the signature; the contract recovers the signer and
  checks it against an accepted-signer set. `expiry` and `nonce` are mandatory — an unbounded
  signed verdict is a replayable authorisation.
- Struct fields: `specHash`, `evidenceHash`, `submittedAt`, `verdictHash`, `verdictPassed`.
- New states `Delivered` and `Arbitrating`.
- **Optional `bytes32 attestationUid` on `submitWork`** — the `CC-036` slot, unused until EAS
  lands. Taking it now avoids a second redeploy.
- `expireTask` becomes a claim the agent makes for themselves, same pull-payment principle.

**Deploy**

Redeploy to Base Sepolia, then call `transferOwnership()` to the HSM key
`0xa8931097540e69B474013D294d0bA6A2cC853e4b` (`CC-059` — a fresh deploy is owned by the deployer).
Re-point `NEXT_PUBLIC_ESCROW_CONTRACT`, and re-derive `ESCROW_DEPLOY_BLOCK` with
`scripts/audit/find-deploy-block.mjs` (`CC-070`).

## Do it now, not later

`verify-escrow-solvency.mjs` measured `USDC.balanceOf(escrow) == totalLocked == 0` on 2026-08-11.
The escrow is empty, so a redeploy costs nothing today and will not be free once real tasks exist.

**Sequencing is load-bearing.** This lands *before* `CC-081` Defect 1's fix so the app layer is
rewritten once against the final ABI rather than twice.

## Acceptance

- `submitWork` → review window → worker claims via `releaseAfterReview` works end to end on Sepolia.
- An agent that does nothing after delivery cannot prevent the worker being paid.
- A signed verdict verifies on-chain; a replayed or expired one is rejected.
- `verify-escrow-solvency.mjs` reports CLEAN against the new deployment.
- `owner()` is the HSM address.
