# CC-038 — Export remaining Linear issues before cancelling the workspace

## Problem
`docs/Linear-Document-Archive.md` preserves the four Linear **documents** (architecture
overview, MVP definition of done, security trust disclosure, HSM deployer checklist). It does
**not** contain the NOR-xxx **issues**.

Issues referenced but not preserved: NOR-174 to NOR-183 (still in code comments), NOR-185,
NOR-195, NOR-196, NOR-292, NOR-304. Anything else in that workspace is currently unrecorded.

Once the workspace is cancelled that history is gone.

## Fix
The Linear connector needs OAuth, which cannot be completed from a non-interactive session.
Authorise it in claude.ai connector settings, then export every issue — id, title, status,
priority, description, comments — into `docs/backlog/` using this convention, mapping the
original id into the `linear:` frontmatter field.

Then cancel Linear.

## Acceptance
Every open NOR issue exists as a CC-xxx file, and closed ones are either archived or
consciously dropped.
