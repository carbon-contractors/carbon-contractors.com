# CC-047 — Migrate git commit signing from SSH to GPG on YubiKey

Migrated from NOR-302.

Generate a GPG key on the YubiKey (prefer generate-on-device so it is non-exportable),
configure git global signing and auto-sign, add the public key to GitHub, confirm the
Verified badge appears, update the WSL config separately from Windows native, record the key
id in Bitwarden, and confirm the Ledger Nano X is still enrolled as backup.

## Note
The three commits made on 2026-07-25 (`.gitattributes`, backlog tracker, this import) are
**unsigned** — they were made with explicit `-c user.name`/`-c user.email` rather than your
global config. If you enforce signing, they will show as unverified.

## Hardware-swap note
See CC-053. If the current SSH signing key lived in a TPM-backed store or behind Windows
Hello, the motherboard swap destroyed it. A YubiKey-resident key would have survived — which
is the argument for this issue.

Related: CC-053, CC-041.
