# CC-019 — Hamburger bars disappear when the mobile menu opens

`src/components/NavBar.tsx:37-39` uses `className={menuOpen ? styles.barOpen : styles.bar}`,
which **replaces** the base class rather than appending it. `.barOpen`
(`src/components/NavBar.module.css:84-92`) declares no width, height or background, so the
bars vanish instead of forming an X.

Fix: `className={`${styles.bar} ${menuOpen ? styles.barOpen : ""}`}`.
