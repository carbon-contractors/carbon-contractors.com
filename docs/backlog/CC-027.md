# CC-027 — README claims Zero PII while the app stores email addresses

`README.md` design constraints state "**Zero PII** — no personal data stored, ever. Wallets
and skills only." The `waitlist` table stores email addresses, `notification_channels` is
explicitly a PII table in the architecture doc, and CC-005 proposes collecting contact
details at signup.

This is a public repo and the claim is quotable. Fix: restate honestly — minimal PII, only
what is needed to notify you, never exposed to agents — and align it with the privacy policy
from CC-008.
