# CC-032 — Sepolia end-to-end lifecycle test

Section 1 of the MVP definition of done (`docs/Linear-Document-Archive.md`) and the last
functional blocker before mainnet. Nothing here has been proven with a real agent.

## Happy path
Register → discover via MCP → x402 fund → notification fires → deliverable submitted →
`confirm_task_completion` → `completeTask()` on-chain → USDC lands in the worker wallet →
DB flips to completed **only after** the tx succeeds. Measure funded → USDC received;
target under 30 seconds for the on-chain portion.

## Unhappy paths
Task expiry and refund; dispute resolution to both outcomes; double completion reverts;
invalid task ID reverts cleanly; over-release reverts; unauthorised caller rejected.

## Edge cases
Worker changes wallet after funding (payout must follow the on-chain address, not the DB);
on-chain failure mid-flight leaves the DB untouched; concurrent completions do not collide
on signer nonces.

Blocked by CC-002 — discovery and profile lookup are broken until wallet casing is fixed.
