# CC-014 — Flipping the coming-soon gate requires a redeploy, not just an env change

## Problem
`middleware.ts:19` and `src/app/page.tsx:4` both read `NEXT_PUBLIC_COMING_SOON` at module
scope. Next.js inlines `NEXT_PUBLIC_*` at build time, and `/` is statically prerendered.

Setting the Vercel env var alone will appear to do nothing. Easy to lose an hour to this.

Also note the flag fails **closed** (`!== "false"`), so the string must be exactly `false`.

## Fix — launch runbook
1. Confirm all six vars required by `src/lib/config.ts:11-26` are present in the Vercel
   **Production** environment at build time.
2. Set `NEXT_PUBLIC_COMING_SOON=false`.
3. Trigger a fresh production deploy (do not promote an old build).
4. Verify `/connect` returns 200 rather than redirecting to `/`.
5. Walk the full signup path on production, on a phone, with the console open.
