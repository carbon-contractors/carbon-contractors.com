# CC-014 — Flipping the coming-soon gate requires a redeploy, not just an env change

## Problem
`middleware.ts:19` and `src/app/page.tsx:4` both read `NEXT_PUBLIC_COMING_SOON` at module
scope. Next.js inlines `NEXT_PUBLIC_*` at build time, and `/` is statically prerendered.

Setting the Vercel env var alone will appear to do nothing. Easy to lose an hour to this.

Also note the flag fails **closed** (`!== "false"`), so the string must be exactly `false`.

## Fix — launch runbook
1. Confirm all six vars required by `src/lib/config.ts:11-26` are present in the Vercel
   **Production** environment at build time.
2. Set `NEXT_PUBLIC_COMING_SOON=false`.
3. Trigger a fresh production deploy (do not promote an old build).
4. Verify `/connect` returns 200 rather than redirecting to `/`.
5. Walk the full signup path on production, on a phone, with the console open.

## Update 2026-08-13 — this gate now verifies published claims, not just the flag

`/learn` Module 7 (*Pseudonymous Is Not Anonymous*) and the `ADR-0002` D2 statements were published
on 2026-08-13 on Aaron's explicit call, on the stated premise that **the site is not live and every
statement will be true by the time it goes public.** That premise is sound — the gate does not lift
until after the mainnet migration (`CC-039`) — but it is currently a thing to remember rather than a
thing that is checked.

Making it mechanical, because this gate is the last moment it can be caught:

**Add to the runbook above, before step 2 (`NEXT_PUBLIC_COMING_SOON=false`):**

- [ ] `verify-retention` passes (`CC-085`) — task content really is deleted on terminal state, so
      *"retains no task content after settlement"* is true.
- [ ] `waitlist` table is dropped and the capture form is gone (`CC-089`) — so *"does not hold
      names, emails, phone numbers"* is true.
- [ ] The evidence path is live (`CC-083`) — the platform holds hashes only, so Module 7's *"photos
      go to storage the hiring agent controls… we keep only a fingerprint"* is true.

- [ ] No testnet-pilot language was ever added (`CC-007` — the decision was not to add it).

**If any box is unticked, the gate does not lift.** Publishing copy that describes an architecture
which does not yet exist is the `CC-029` defect at a larger scale, and privacy claims are the one
category with statutory teeth — `ADR-0002` D8 notes the serious-invasion-of-privacy tort ignores the
small-business turnover exemption entirely.

Priority stays **P2** — it is still a runbook, not a defect.
