# CC-002 — Wallet case mismatch — every registered worker 404s on profile lookup

## Problem
`src/app/api/register/route.ts:135` inserts `wallet: wallet` — the raw EIP-55 checksummed,
mixed-case address supplied by wagmi. But `src/lib/db/whitepages.ts:50` looks it up with
`.eq("wallet", wallet.toLowerCase())`.

`humans.wallet` is `TEXT NOT NULL UNIQUE` (`supabase/migrations/001_init.sql:6`) — case
sensitive, with no normalising constraint.

Consequences:
- `/api/profile` returns 404 for every worker who has ever registered
- the dashboard profile card never renders (`src/app/dashboard/page.tsx:426`)
- the MCP `get_contractor` tool cannot find anybody
- the same person can register twice under different casing

## Fix
1. Normalise on write: `wallet.toLowerCase()` in the register route.
2. Normalise on every read path in `whitepages.ts` (audit all of them).
3. Migration: backfill `UPDATE humans SET wallet = lower(wallet)`, then add
   `CHECK (wallet = lower(wallet))` so it cannot regress.
4. Check `tasks.to_human_wallet` / `from_agent_wallet` for the same class of bug.

## Acceptance
Register a fresh wallet, land on the dashboard, and see the profile card populated.
