# CC-063 — Vercel Hobby violates ToS for commercial SaaS — migrate to Pro or hybrid Cloudflare

## Problem

Carbon Contractors is running on Vercel's **Hobby (free) tier**, which explicitly prohibits commercial use.
The Hobby plan is for "personal projects, learning, and non-commercial use only." Running a commercial 
SaaS marketplace — where AI agents discover human workers, post tasks, coordinate escrow payments, and 
register for work — violates Vercel's Terms of Service.

**Risk:** Vercel can suspend the account without warning for ToS violations. The platform goes dark.

Additionally, the current Vercel setup has operational fragility:

1. **Bandwidth overage exposure:** 100 GB/month hard cap on Hobby; no spend limit available on Pro.
   A traffic spike or DDoS attack can generate unexpected $0.15/GB charges. Users report $1,000+ bills 
   from runaway costs.

2. **No DDoS protection included:** Vercel's Pro plan includes WAF but not unmetered DDoS mitigation.
   A malicious agent hammering the API discovery endpoints or a coordinated DDoS hits your bill before 
   you can react.

3. **Serverless CPU overage unpredictable:** MCP tool invocations and task completion handlers meter 
   separately. Pro includes no CPU minutes free; after 4 hours/month, you pay $0.128/hour.

## Fix

**Option A: Migrate fully to Cloudflare**

- Cloudflare Pro: $20/month (same as Vercel Pro, but includes unmetered DDoS + no bandwidth charges)
- Workers for API backend: $0.30/million requests + $0.02/million CPU-ms
- D1 (serverless SQL) or Hyperdrive (proxy to Supabase)
- **Total cost:** ~$50–$100/month depending on volume; 7–15x cheaper than Vercel for equivalent throughput
- **Compliance:** Commercial use permitted on all plans
- **Security:** DDoS protection + WAF included, rate limiting on Pro

**Downside:** Requires rewriting the backend from Next.js API routes to Workers. The MCP server 
(`src/lib/mcp/server.ts`) and `/api/*` routes would move to Cloudflare, away from your tested, 
working Node.js environment. Workers runs in V8 isolates, not Node.js — no native modules, limited 
async patterns, different error handling.

**Option B: Hybrid (recommended for now)**

- **Frontend:** Keep Vercel Pro ($20/month) for Next.js App Router (wallet flows, SSR, already tested)
- **API backend:** Move to Cloudflare Workers
- **Database:** Supabase (unchanged) + Hyperdrive for Workers connectivity

**Cost:** ~$50–$70/month ($20 Vercel + $5–$50 Cloudflare)
**Compliance:** Pro allows commercial use
**Security:** DDoS protection on API layer (where agents hammer hardest)
**Timeline:** Shorter than full migration; incremental rewrite of API routes only

## Acceptance

- [ ] **Immediate:** Move from Vercel Hobby to **Vercel Pro** ($20/month seat) to achieve compliance
      while evaluating longer-term infrastructure
- [ ] Document the choice (this issue) in the codebase so future sessions know why Pro was chosen
      over free tier
- [ ] **Medium term (next sprint):** Prototype MCP server on Cloudflare Workers with Hyperdrive 
      to Supabase. Measure performance, CPU cost, and cold-start latency. Compare to current Vercel 
      baseline.
- [ ] If Workers prototype is viable, plan incremental cutover of `/api/basedhuman.mcp` and auth 
      routes to Cloudflare. No frontend changes needed.
- [ ] If Workers prototype is not viable (latency, cost, or developer experience), stay on Vercel Pro 
      and document that decision with measured data.

**Verification:** 
- Vercel account switched to Pro plan, first invoice shows $20 charge
- Cloudflare Workers prototype runs a single MCP tool end-to-end (e.g., list workers)
- Latency and error rates are measured and documented

## Notes

- **Vercel CSP and wallet flows tested on Hobby.** Moving to Pro does not change the platform; 
  all wallet tests remain valid. Only cost and ToS compliance change.
- **Cloudflare Workers is a **different** execution model.** It is not a drop-in replacement. 
  Test it before committing.
- **Hybrid path is safer.** Keep the frontend where it works; experiment with Workers for the API. 
  If Workers doesn't pan out, you're still on compliant Pro with a working system.
- See [Cloudflare Pricing 2026](https://www.cloudflare.com/plans/) for current rates and Workers 
  comparison.
