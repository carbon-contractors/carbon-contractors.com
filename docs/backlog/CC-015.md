# CC-015 — Waitlist has no honeypot or captcha

`src/app/api/waitlist/route.ts` validates the email shape and upserts with
`ignoreDuplicates`, but the only throttle is the shared 60/min/IP middleware bucket across
all of `/api`. Once the site is promoted, a trivial script can inject thousands of fake
addresses and poison the one asset worth having.

Fix: add a honeypot field plus a dedicated tighter rate limit for this route. Consider
double opt-in, which also helps the Spam Act position in CC-008.
