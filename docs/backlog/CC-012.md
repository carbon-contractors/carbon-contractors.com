# CC-012 — No OpenGraph or Twitter metadata — every shared link renders as a blank card

## Problem
`src/app/layout.tsx:13-17` sets title and description only. There is no `metadataBase`,
no `openGraph`, no `twitter`, and no share image — `public/` holds `base-mark.svg` plus
leftover Next.js starter SVGs.

Since the entire plan is to promote the link, this is directly load-bearing: every post on
LinkedIn, X or Slack will show a grey box.

## Fix
Add `metadataBase`, `openGraph` and `twitter` blocks in `layout.tsx`, plus a 1200x630 image
in `public/`. Validate with a card debugger before promoting.
