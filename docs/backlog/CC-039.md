## Gates

launch stable, before any of the below starts. `CC-034` already said this explicitly ("do not
start until CC-032 and CC-035 are green") before this issue existed to make it structural.

**Security (mainnet-specific)** — re-run CC-035's OWASP/Web3 sweep and `npm audit` against
whatever's changed since the public launch; do not assume the public-launch pass still holds
after however long the site's been live on testnet first

contract address and network var to mainnet)

the homepage no longer carry testnet-specific language once real money is live
**Smoke test** — full fund → complete → pay lifecycle on mainnet, plus dispute flow
**Post go-live** — 48-hour watch checks

are removed from the active gate list rather than left as stale references.
